### **核心理念：**
1. **两人都参与数据库设计，但有明确分工**
2. **每人负责一个完整角色的数据层+业务层**
3. **通过"接口契约"和"数据边界"实现独立开发**
### **数据库设计分工方案：**

#### **A的数据库责任区（系统配置层）**
```sql
-- 1. 学期表（term） - 系统基础
CREATE TABLE term (
    term_id VARCHAR(20) PRIMARY KEY,
    term_name VARCHAR(50),
    enroll_start DATETIME,  -- 选课开始
    enroll_end DATETIME,    -- 选课结束
    drop_deadline DATETIME  -- 退课截止
);

-- 2. 教学班表（course_class） - 课程安排
CREATE TABLE course_class (
    class_id INT PRIMARY KEY AUTO_INCREMENT,
    course_id INT,
    teacher_id INT,
    term_id VARCHAR(20),
    class_time VARCHAR(100),  -- "周一1-2节"
    location VARCHAR(100),
    capacity INT DEFAULT 60
);

-- 3. 学分规则表（credit_rule） - 业务规则
CREATE TABLE credit_rule (
    rule_id INT PRIMARY KEY AUTO_INCREMENT,
    rule_name VARCHAR(50),
    term_id VARCHAR(20),
    max_credits INT DEFAULT 20
);
```
#### **B的数据库责任区（业务交互层）**
```sql
-- 4. 选课表（enrollment） - 核心业务表
CREATE TABLE enrollment (
    enrollment_id INT PRIMARY KEY AUTO_INCREMENT,
    student_id INT,
    class_id INT,
    term_id VARCHAR(20),
    status ENUM('ENROLLED', 'DROPPED') DEFAULT 'ENROLLED',
    grade DECIMAL(4,1),
    grade_status ENUM('DRAFT', 'PUBLISHED') DEFAULT 'DRAFT',
    created_at DATETIME,
    
    -- B需要设计的约束：
    -- 1. 同一学生同一学期同一课程不能重复选课
    -- 2. 状态转换约束（如：有成绩后不能直接退课？）
    -- 3. 索引优化设计
);

-- 5. 时间冲突检查辅助表（如果需要）
CREATE TABLE class_schedule (
    class_id INT,
    week_day INT,      -- 周几（1-7）
    start_slot INT,    -- 开始节次（1-12）
    end_slot INT,      -- 结束节次
    PRIMARY KEY (class_id)
);
```
